# NEXUS — Cyborg-Themed Landing Page

Responsive cyberpunk concept landing page for the Techfest IIT Bombay Web Development task.

## Features
- Responsive desktop, tablet, and mobile layout
- Animated CSS cybernetic core, orbital rings, telemetry chips, and ticker
- Three feature cards, principles section, contact CTA, and footer
- Mobile navigation, scroll reveal, active section navigation
- Reduced-motion accessibility support
- Vanilla HTML, CSS, and JavaScript; no build step or API keys

## Run locally
Open `index.html` in a modern browser. For live reload, use VS Code with the Live Server extension.

## Deploy using GitHub Pages
1. Create a public GitHub repository (e.g. `nexus-cyborg-landing-page`).
2. Upload `index.html`, `styles.css`, `script.js`, and the `assets` folder to the repository root.
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch**, choose `main` and `/(root)`, then save.
5. Wait for GitHub Pages to publish the site and copy the provided URL.

## Demo recording (30–60 seconds)
Record the hero and animated core, scroll through Systems and Protocol, then show the contact/footer and mobile layout. On Windows, try **Win + Alt + R** for Xbox Game Bar recording if enabled. Upload the MP4 to Google Drive and set access to **Anyone with the link — Viewer**.
